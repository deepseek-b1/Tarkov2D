# 与「合并版」exe 的差异说明

本文件记录一次**字节码级比对**的结论，用来回答一个具体问题：
为什么本仓库编译出来的包，和流传的 `Tarkov2D-2.13.2-Win10-64位-合并版.exe` 不是同一个东西。

## 比对对象与方法

| | 对象 |
|---|---|
| A | `Tarkov2D-2.13.2-Win10-64位-合并版.exe`，9.54 MB，SHA-256 `be04d9f3…`，内嵌 CPython 3.8 x64（PyInstaller 单文件） |
| B | 本仓库 `main` 的 2.13.1 源码（commit `3ab09ff`，34 个 `.py`） |

方法：解包 A 的 PyInstaller 归档 → 取出 `PYZ-00.pyz` → 逐个模块 zlib 解压得到 3.8 字节码；
用 **CPython 3.8.10** 把 B 的同名源码编译成字节码；对每个模块做**结构化比较**——
比较 `co_code`（指令）、`co_consts`（常量，递归进嵌套代码对象）、`co_names` / `co_varnames` /
`co_argcount` / `co_flags`，**忽略文件名与行号表**（`co_filename`、`co_lnotab`）。
判定只有「完全一致」或「有差异」，不掺主观判断。

## 总览

- A 的 PYZ 共 278 个模块，其中游戏模块 25 个与 B 同名可比。
- **完全一致 8 个**：`accounts`、`assault`、`bindings`、`coop`、`login`、`mystery`、`touch`、`updater`。
- **有差异 17 个**：`audio`、`enemy`、`game`、`hideout`、`intro`、`inventory`、`maps`、`net`、
  `npc`、`quests`、`raid`、`raid_ui`、`save`、`selftest`、`settings`、`uikit`、`world`。
- **A 独有模块 3 个**：`netid`、`newmaps`、`progress`。
- **B 独有**：`story`、`storytest`（剧情模式）。`main` 是 PyInstaller 入口脚本，不在 PYZ 内。

**结论：A 不是由本仓库编译出来的。** 它是另一条分支——删掉了剧情与人质模式，换成了探索模式、
4 人联机、等级成长线等本仓库没有的内容。

## A 有、B 没有

1. **探索模式「常务公司」**（`newmaps`，19 个代码对象）
   六层：地下车库 + 1F~5F 顶楼；每层布局不同（16 间办公室 / 工位柱阵 / 实验层 / 宿舍 / 停机坪 + 塔台）；
   13 名研究员待救援；顶楼停机坪发信号弹叫直升机撤离。
   常量：`EXPLORE_FLOOR_ENEMY_CAP`、`HELI_PAD_TILES`、`HELI_ROOF_FLOOR`、`HELI_DEFEND_TIME`、
   `HELI_WAVE_INTERVAL/MAX/SIZE`、`HELI_WINDOW_TIME`、`RESEARCHER_*`。
2. **4 人局域网联机**（原为 2 人）：`_PLAYER_STATE`、号位 2/3/4、`[net] 加入 P%d`。
3. **实体联机编号**（`netid`）：修正「敌人死亡/刷新导致下标错位、每帧重建对象」的问题。
4. **肾上腺素系统**：`ADRENALINE_TIME / HP_MUL / REGEN / SPEED_MUL / MAX_STACK`。
5. **音量系统**：`vol_master / vol_gun / vol_ui / vol_muted`、`GUN_SFX` 分组、`VOL_DEFAULT`、设置页滑条。
6. **部门好感度折扣**：`FAVOR_DEPTS / FAVOR_NAMES / FAVOR_DISCOUNT / FAVOR_MAX_TIER / FAVOR_PER_TIER`。
7. **等级与奖励线**（`progress`，27 个代码对象）：经验/升级（Lv150 封顶）、
   卢布与全装包奖励档（60 万 → 1.5 亿卢布、3~6 级全装包、M139 / AX-50 特种机枪）。
8. **队友强化参数**：`ALLY_DMG_MUL / ALLY_HP_MUL / ALLY_SPREAD`。

## B 有、A 没有

1. **剧情模式全套**：`story.py`、`storytest.py` 两个模块整个不存在，引用亦被清除
   （`is_story`、`story_mod`、`story_snap`、`story_issued`、`DIA`、`PERIODS`、`ENDINGS`、`CHOICE_FX`）。
   即「八时段 × 两次出击」「六个结局」「对话与选择后果」这套内容在 A 中被删除。
2. **人质模式**：`Hostage` 类、`HOSTAGE_COUNT`、`HOSTAGE_ENEMIES`、`HOSTAGE_RESCUE_TIME`，
   以及人质大楼 / 室内图 / 城区大图（`build_indoor`、`build_city`、`CITY_*`）。

## 对「把实时更新做进合并版」的影响

- 本仓库的实时更新**无法直接移植**到 A：A 是编译好的 3.8 字节码，模块结构与功能集合都不同。
- 用本仓库源码编译的包**永远不会等于 A**：本仓库没有探索模式/4 人联机/等级线，
  而 A 删掉了剧情与人质。
- 若要在「合并版」上加实时更新，可选路径：
  1. 取得 A 对应的**源码分支**，在源码上实现后重新打包（推荐）；
  2. 对 A 的字节码做补丁式注入（可行但脆弱，且需同时改主循环与网络/存档层）；
  3. 使用本仓库这条线（已含实时更新与 58 项自检），接受功能集差异。

## 复现方式

```text
1. 解包 exe 的 PyInstaller CArchive，取出 PYZ-00.pyz 并逐模块 zlib 解压
2. 用 CPython 3.8.10 编译本仓库同名 .py
3. 比较 code object 的 co_code / co_consts / co_names / co_varnames / 参数与 flags（忽略行号表）
```
