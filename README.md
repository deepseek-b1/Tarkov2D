# Tarkov2D — 类塔科夫 2D 搜打撤

纯 Python (pygame) 制作的俯视角"搜刮-战斗-撤离"(Extraction Shooter)游戏。
无任何外部素材:地图、图标、音效全部程序生成。

## 启动

- **直接双击 EXE**:`dist\Tarkov2D.exe`(单文件、免安装);每次启动会先**检查更新**
- 或用 Python 运行:`pip install pygame` 后 `python main.py`
- ★ **先登录**:输入「名字 + 密码」进入自己的存档(见下「账号与存档」)
- **手机模式**:`python main.py --touch`(或在藏身处点「手机模式:开/关」)
- 重新打包:双击 `build_exe.bat`(需 `pip install pyinstaller`)

## 账号与存档(2.12.0)

启动时是登录界面:**一个「名字 + 密码」= 一份独立存档**(同一台电脑可以多人各玩各的)。

- **老账号**:左边点名字自动填入 → 输密码 → 「登录并进入」
- **新账号**:直接输名字(字母/数字/`_`/`-`,最多 12 位)+ 密码(至少 3 位)+ 再输一次
  → 「创建账号并进入」(**第一次建号会把老的 `save.json` 自动并进这个账号**,进度不丢)
- **密码只存 PBKDF2 加盐哈希**(不存明文):忘了密码只能删档重来
  (存档在 `%LOCALAPPDATA%\Tarkov2D\accounts\<名字>\save.json`,也可以直接删那个目录)
- 「删除该账号」需要密码,点两次确认,存档会备份成 `.deleted-*`
- **换账号**:藏身处「设置」页右上角「**切换账号**」(只回登录界面,不丢进度)
- 电脑上可以直接打字(Tab 换输入框 / 回车 = 进入 / ESC = 清空当前框),也可以点屏幕键盘;
  手机上只有一个屏幕键盘,必须点它

## 手机怎么玩?(三种方式)

同一套代码同时支持电脑与手机,之后每次更新两端一起更新。

**方式 A:网页版(最快,手机浏览器直接玩)** ⭐ 推荐先试
```
python -m pygbag --build webapp      # 打包(首次会下载 emscripten,较慢)
serve_web.bat                        # 启动服务器,窗口里会显示本机 IP
```
手机连**同一个 Wi-Fi**,浏览器打开 `http://<电脑IP>:8000` 即可开玩;
用浏览器菜单「添加到主屏幕」就相当于一个 App 图标(网页版存档放在浏览器存储里)。

**方式 B:GitHub Actions 打真 APK(免费,不用自己装 Linux)** ⭐ 要 APK 用这个
1. 把整个项目推到 GitHub 仓库
2. 仓库 **Actions → Build Android APK → Run workflow**(或推一个 `v1.0.7` 标签)
3. 构建完成后在 Artifacts 下载 `Tarkov2D-apk.zip`,里面的 apk 传到手机安装即可
   (工作流已写好:`.github/workflows/android.yml`)

**方式 C:本地 Linux / WSL 打 APK**
```bash
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool \
    pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo6 cmake \
    libffi-dev libssl-dev
pip install buildozer cython
buildozer -v android debug      # 产出 bin/tarkov2d-1.0.7-debug.apk
```
配置见 `buildozer.spec`(横屏、全屏、pygame 依赖、中文字体都已配好)。

**手机操作**:左半屏拖动 = 移动(推一半 = 半速);右侧按钮 = 开火 / 架枪 / 装填 / 打药 / 搜刮 / 背包;
**★ 自动锁敌** —— 自动瞄准视野内最近的敌人(橙色瞄准框),手机不用自己瞄准;
弹窗(背包/搜刮)直接用手指点格子。

**电脑上想试手机操作**:藏身处点「手机模式:开/关」,或 `python main.py --touch`。

## 自动更新

启动时读取更新清单,发现更高版本就自动下载、替换自身并重启:

1. 检查顺序:EXE 同目录的 `version.json` → `settings.UPDATE_MANIFEST_URL`(默认 `http://127.0.0.1:8765/version.json`)
2. 清单格式:`{"version": "1.0.2", "url": "Tarkov2D.exe", "notes": "更新说明"}`
3. 找到新版 → 下载为 `Tarkov2D.new.exe` → 批处理等本进程退出后**重试覆盖**旧 EXE → 自动重启游戏
4. 没有服务器 / 检查失败时静默跳过,不影响正常游戏

**发布一次更新**:
```
python publish_update.py 1.0.2 "新增 XXX 内容"   # 自动改版本号 + 打包 + 写清单
serve_update.bat                                 # 启动本地更新服务器(8765 端口)
```
把 `update_server\` 里的 `Tarkov2D.exe` 与 `version.json` 放到任意 HTTP 服务器(或 GitHub raw),
再把 `settings.UPDATE_MANIFEST_URL` 改成对应地址,玩家端下次启动就会自动升级。

**其他参数**:`--no-update`(跳过更新检查)、`--version`(输出版本号;
运行版本会记录到 `%LOCALAPPDATA%\Tarkov2D\last_run_version.txt`)。

## 游戏模式(藏身处右侧「游戏模式」切换)

**① 搜打撤**(默认):自由搜刮 → 找撤离点撤离;可选地图与难度,死亡掉光带入装备。

**①·双人合作(2.12.0)**:在「游戏模式」标题右边点「**双人合作:开**」——
**同一台电脑、一个键盘两个人合作打 AI**(只对搜打撤生效,手机模式不可用):

- **P1(你)**:WASD 移动 + 鼠标瞄准 + 左键开火,和单人一样
- **P2(队友)**:方向键移动,**自动瞄准视野内最近的敌人**;
  **右Shift** 开火(按住连发 / 点按点射)、**右Ctrl 或 /** 交互、**小键盘 0 或 .** 换弹、
  **小键盘 1 或 ,** 打药
- 双人模式下 P1 的移动会让出方向键(WASD 照旧),两人不会一起动
- **P2 靠近箱子按交互 = 自动搜刮**:逐件读条搜出身份后直接收进自己背包(不用鼠标点界面)
- 屏幕上只有一张画面:P1/P2 的视野是**并集**(谁看到就算看到),
  左上角常驻 **P2 血量/弹药面板**,画面上蓝圈是 P2
- **两人都是系统配发的装备**(和突袭同一套回收机制):仓库里自己的东西不会被碰;
  撤离 = 两人背包里的战利品都并进仓库;**谁倒下另一个还能接着打**,
  只有两人都倒下才算失败(那一局搜到的就丢了)

**② 人质解救**(室内近战):
- 进入专门的「**人质大楼**」:**95% 以上是房间与走廊**,只在南侧留一小块室外集散区
- **目标**:找到并解救 **4 名人质**(靠近按 **E**,站定读条 2.5 秒),全部救出后撤离;
  结算会显示 `人质 4/4 —— 任务完成!`(只救一半撤离则显示未完成)
- **队友 AI ×3**:跟着你推进、自动开火;**倒地后靠近按 E 拉起**(读条 2 秒)
- **敌人最多 6 个**,开局分散在不同房间
- **拐角死角**:每个房间拐角都有暗色死角标记,敌人爱蹲守 —— **进门先贴墙排点,别正面冲**
- 室内别站走廊正中,开阔地容易吃交叉火力

**③ 黑暗行动(夜战)** —— 默认**强化封锁**:
- 整张图黑到伸手不见五指,**只有光源范围内看得见东西**;敌人也**只有亮区里才显示**
  (手机自动锁敌同样只锁亮区里的敌人)
- 两种光源(交易所买,可二选一也可都带):
  - **枪上照明配件**(装在「照明」槽):**战术手电** 射程 430(¥16,000)/
    **强光探照灯** 射程 580(¥45,000)—— **锥形**亮区,跟着准星方向转
  - **夜视头盔**(新增「头盔」装备槽,和护甲并存):**PNV-10T** 半径 300(¥180,000)/
    **GPNVG-18** 半径 440(¥480,000)—— **全向圆形**亮区、带夜视绿,不用瞄准
- **不带光源**:只看得见脚边一小圈(92px),基本等于瞎打
- 照明也算**配件**:先装备武器,再从仓库点手电装到枪上
- **敌人不受你的灯光限制**:黑暗中他们照样能看见你、朝你开枪(只有「你看不看得见他」被限制)
- 装在枪上的照明槽位:除 M139 机枪 / 火箭筒外都支持(手枪也能装)

## 玩法循环

1. **藏身处整备**:把仓库里的武器、护甲、弹药、医疗品配置到出战栏(点击即可,自动旋转摆放入格)
2. **选择难度**:`简单`(敌人孱弱迟钝)/ `封锁`(标准强度)/ `强化封锁`(凶猛人多,物资更肥)
3. **进入战局**:12 分钟内搜刮物资箱、军械箱、医疗箱、保险柜,击杀拾荒者舔包
4. **撤离**:走向任意撤离点(屏幕边缘有绿色箭头指示),站定 3 秒完成撤离
5. **死亡/超时**:带入的装备全部丢失,搜刮到的东西也没了 —— 谨慎行事
6. **交易所**(藏身处右下角按钮):花卢布购买武器/弹药/医疗/护甲;搜刮带回的贵重物点一下即可出售(回收价 = 原价 60%)
7. 撤离成功的东西回到仓库,循环往复,积累战利品

| WASD / 方向键 | 移动 |
| Shift | 慢走 |
| 鼠标 | 瞄准 |
| 左键 | 射击(全自动武器可长按) |
| 右键(长按) | 架枪:提升精度(除狙击枪外所有枪械) |

### 搜刮与治疗(要花时间)

- **搜刮**:靠近容器按 E 打开 —— 里面的东西**一开始是「未知」的**(只看得见占几格的形状),
  点它开始搜索,**1~2 秒/件**(按占格数,大件更慢),搜出来才知道**是什么**;
  再点一下(或按「全部拿走」)才收进背包。**走远或关掉窗口会中断搜索**
- **打药**:按 H / 点医疗品后要读条 1~3 秒(按治疗量);**边走边打进度减半**
- **丢弃**:电脑右键丢弃;手机没有右键,背包面板里点「**丢弃模式:开**」,
  之后点物品或装备槽就是丢在脚边
- **换装不再卡住**:换枪/换甲/换头盔时,旧装备塞不进背包会**自动丢在脚边**
  (以前直接拒绝,看起来像"卡死")

### 动作对移动速度的影响

| 状态 | 移动速度 |
| --- | --- |
| 正常 | 100% |
| **架枪 / 瞄准** | **20%**(减 80%) |
| **换弹中** | **40%**(大幅减速) |
| M139 机枪 · 换弹或架枪 | **完全不能移动** |

## 性能(2.3.0)

手机端 120fps 的关键改动(原理与实测见 `ANDROID-BUILD.md` 第 10 节):

- **战争迷雾两级缓存**:视野多边形只在玩家移动 ≥6px 时重算;「可见敌人集合」每 0.1 秒
  或在移动时刷新一次。敌人 AI 的 `sees_player`、索敌 `threat_for` 与绘制可见判定
  全部读这份缓存 —— 以前**每个敌人每帧各打一条 DDA 射线**,现在是 O(1) 查表
- **迷雾合成层按版本缓存**:玩家不动时每帧只剩一次 `BLEND_RGB_MULT` 整屏 blit
- **屏幕裁剪**:屏外的敌人不再参与绘制
- **HUD 面板缓存**:对话框暗幕 / 提示条 / 通知条等小面板复用 Surface,不再每帧分配
- **帧率解锁 + dt 无关粒子阻尼**:粒子运动与帧率解耦,120fps 下观感与 60fps 一致

自测基准(本机 i5-4210U,同一台机器、同一套代码,固定种子,交叉重复取最小值):

| 场景 | 2.2.0 | **2.3.0** |
| --- | --- | --- |
| 藏身处 | 3.6 ms · 277 fps | **0.65 ms · 1541 fps** |
| 战局(静止/搜刮) | 11.2 ms · 89 fps | **3.17 ms · 315 fps** |
| 战局(**持续移动**,迷雾每次重算) | — | **6.17 ms · 162 fps** |
| 战局 + 背包 | 7.7 ms · 130 fps | **3.89 ms · 257 fps** |
| 战局 + 搜刮窗 | 7.1 ms · 141 fps | **3.29 ms · 304 fps** |
| 战局 + 交火(粒子) | 8.3 ms · 121 fps | **5.46 ms · 183 fps** |

这台 2014 年的 15W i5 上最差场景都有 162 fps(6.2 ms/帧),120 fps 的预算是 8.3 ms —— 现代
手机的单核性能普遍不低于它,所以手机端目标 120 fps 是稳的(以游戏内右上角 FPS 为准)。

## 系统说明

- **塔科夫式格子背包**:物品占据不同尺寸(1×1 到 5×2),自动旋转放入;
  弹药按口径堆叠、每组最多 **120 发**;背包界面有「整理弹药」按钮,点击后弹窗询问,一键把散弹叠放成组
- **战争迷雾**:只有视线内的敌人才可见;枪声会吸引附近的拾荒者
- **敌人**:刀匪(近战)、拾荒枪手、霰弹拾荒者、突击拾荒者,会听声、追击、射击
- **护甲**:按百分比减伤,重甲会降低移速;5 级甲减伤 89%/81%/75%,6 级重甲(6B45 / BT201)减伤 97%/99% 并带**倒地自救**(每局一次,受致命伤时救命);
  另外还有 **1~6 级头盔**(额外减伤乘在护甲之后:1 级 6% → 6 级 40%),和护甲槽并存

## 常见问题

- **双击 EXE 被 SmartScreen 拦截**:未签名 EXE 的正常现象,点"仍要运行";
  或改用 `python main.py`
- **崩溃**:游戏会写崩溃日志到 `%LOCALAPPDATA%\Tarkov2D\crash.log`
- **没声音**:无音频设备的机器会自动静音,不影响游戏
